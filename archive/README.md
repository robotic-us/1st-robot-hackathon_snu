# Historical project material

This directory keeps small, useful records from earlier working folders while
leaving the primary source tree focused on the final shoe-valet prototype.

- `early-prototypes/` — earlier webcam, cloud-vision, and data-generation
  prototypes, plus their small reference images and configuration.
- `general-shoe-baseline/` — earlier general-shoe detector source, data
  configuration, and selected training result.
- `raw-captures/` — original shoe captures and manual labels used in the final
  pose workflow.
- `floor-references/` — original fixed-camera floor images.

This is intentionally an archive, not the recommended runtime entry point.
Use `operations/` and `vision/` for the current project.
